# Employee Management System

A command-line employee management system built with Python.

## Features

- Add, view, find, update, and delete employees
- Department summary with employee count and total salary
- Save and load data using JSON
- Interactive menu system

## Data Structure

Employees are stored as a list of dictionaries:

```python
employees = [
    {"name": "Alice", "dpt": "Engineering", "salary": 75000},
    {"name": "Bob", "dpt": "Sales", "salary": 55000}
]
```
